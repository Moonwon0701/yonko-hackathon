  - 패배 (12): 내내 대등하다 마지막 15턴에 중앙 건물을 연달아 뺏김(이번 PR에서는 다루지 않음)

  - 원인: 전투병을 "적 전투병 + 추가 인원"까지 먼저 채운 뒤 깃발병을 만들었다. 상대가 전투병을 더 뽑으면 자원이
    전부 전투병으로 갔다. 깃발병이 0명일 때의 조건(`nf or budget >= fc + wc`)도 깃발병 몫을 남기지 못했다.
  - 수정: 깃발병이 `MIN_FLAGS`(2)보다 적으면 목표가 있는 한 그 몫을 먼저 만들고, 그다음 전투병, 남으면 깃발병·전투병
    순서. 옛 조건은 지움
- `tests/test_strategy.py`: 새 테스트 `test_flags_come_before_warriors_when_below_minimum`(수정 전 코드에서 실패 확인).
