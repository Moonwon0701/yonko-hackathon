  효과가 있는지 기록하기 위해

## 범위 — LLM이 한 것

- 1번: 원문(규칙서 1장 시드, 운영 규칙 3-나·다)에서 확인되는 것과 안 되는 것을 나누고, 맵별 특화는 사실상
  공개 전 점수를 미리 아는 것이라 허용 여부도 물어야 한다고 판단, 운영팀 질문 초안 작성
- 3번: 새 리플레이(`high_02`)가 수정 전 경기와 같은 맵·같은 상대라 경기 진행이 똑같음을 확인하고 응답 시간 비교
  (최대 179 → 83 ms, 중앙 82.5 → 22.5 ms)
- `docs/game-api.md`: 등록 진영 Y(모의 전투 20경기 근거), 11절에 맵 구성 질문 3개
- `docs/benchmarks.md`: 서버 응답 시간 한 줄, `docs/simulator.md`: 경기 수 갱신
- `data/server-replays/2026-09-27_high_02/`: 새 리플레이 1개
- 5번(첫 턴 깃발병 우선 생산) 실험: 깃발병이 N명보다 적으면 전투병보다 먼저 만드는 규칙을 N=0~3으로 서버 맵 20경기·
  시드 맵 100경기, N=1·3은 새 시드 200경기 더 비교. 합계 320경기에서 N=1 52.5%, N=3 57.5%로 모두 구간이 50%를 포함해
  효과가 확인되지 않음 → 코드는 버리고 결과만 `docs/benchmarks.md`에 기록
- 다른 세션이 남긴 메모리에서 공식 개발도구(`dev_tool.zip`)를 알게 되어 `docs/PLATFORM_OPERATIONS.md`를 읽고, 모의 전투
  맵이 공개 시드 0~9라는 것(맵 질문 1번 해결)과 출력 한도 초과는 몰수라는 것을 11절에 기록. 공식 맵 생성기로 시드
  0~9가 우리 서버 맵과 같은지 실행해 보려 했으나 외부 코드 실행이 권한 분류기에 막혀 확인하지 못함
