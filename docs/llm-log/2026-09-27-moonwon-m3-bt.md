## 범위 — LLM이 한 것

- 1번: M2 vs M1 경기에서 깃발 뽑기가 많은 맵을 찾아(seed 3) 리플레이를 열고, 같은 건물 반복 탈환을 지적
- `agent/strategy.py`(현진 담당): `Profile`·`PROFILES`, `phase_conditions`, `select_phase`(Selector + 히스테리시스),
  `pressured_buildings`, `guard_tasks`, `estimated_score`, `note`. 아래층 `assign`·전투병 목표 수가 국면 가중치를 씀
- `main.py`: 턴 로그에 국면 이름 추가
- `tests/test_strategy.py`: M3 테스트 4개. 지키기 테스트는 처음 쓴 판이 지키기 없이도 통과하는 것을 발견해 고쳤고,
  지키기 과제를 빼면 실패하는 것을 확인
- 비교 실험: 국면 끔(지키기만) 92승, 위협 기준 변형 2개(92승, 90승) → 첫 값 유지
- `docs/benchmarks.md`, `docs/roadmap.md` 갱신
- 국면 조건·가중치 수치는 LLM이 정한 첫 값
