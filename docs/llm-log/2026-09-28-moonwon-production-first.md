# 리더보드 리플레이 전략 분석 + 깃발병 총원 상한

- 날짜: 2026-09-28
- 요청한 사람: 문원
- 모델: Claude Opus 5.5 (`claude-opus-5-5`), Claude Code CLI
- PR: (아직 없음, 브랜치 `moonwon/production-first`)

## 프롬프트 (원문 그대로)

1. > 지금 개선들이 다 너무 마이크로해. 좀더 큼직한 변경이 필요할 것 같아. 상대봇들과 했던 경기들 특히 리더보드 상위권에 있는 봇들 리플레이 분석해서 전략 경향 분석해보자.
2. > 1번부터 구현해서 벤치마크 돌려줘

## 목적

- 작은 조정 대신, 상대 봇과의 실제 경기에서 승패를 가르는 큰 경향을 찾고 그에 맞는 전략 변경을 시험

## 범위 — LLM이 한 것

- 분석(1번, 저장소 밖 임시 스크립트): `data/server-replays/`의 9/27·9/28 리더보드 리플레이 20개(중복 2개 제외 18경기,
  12승 6패). 리플레이에는 상대 팀 이름이 없어 이긴 경기·진 경기로 나눠 비교
  - 전투병은 1:1 상쇄라 양쪽 사망 수가 같음 → 우리 SPAWN 명령과 유닛 수로 사망 수를 구하고, 상대 생산량과 지출
    (전투병·깃발병·점령)을 역산
  - 20턴까지 수입은 같지만 우리가 깃발병에 더 써서 전투병이 10~15명 적음. 진 경기는 격차가 이어져 공학관·학생회관을
    잃고 무너짐. 오프닝(첫 공학관·학생회관 시점)은 양쪽이 같음
  - 전투 위치·병력 분포: 이긴 경기는 전투가 적 진영에서, 진 경기는 우리 진영에서. 강한 상대는 전투병을 넓게 펼쳐 전진
  - 큰 변경 후보 3개 제안: 전투병 생산 극대화(깃발병 절제·경제 건물), 상대 경제 건물 공격, 전투병 벽 전선
- 구현(2번): 1번 후보
  - `agent/strategy.py`: 깃발병 총원 상한 `MAX_FLAGS`(6) 추가 — 점령 과제가 많아도 깃발병은 6명까지만, 남는 자원은
    전투병. 생산 잎 이름·docstring 갱신
  - `tests/test_strategy.py`: 상한 테스트 1개(상한 99에서 실패하는 것 확인)
  - `docs/roadmap.md`: 트리 전문을 `tree_text()` 출력으로 갱신(#44 전선 잎도 이제 반영)
  - `docs/benchmarks.md`: 분석 1줄 + 반영 1줄 + 실험 3줄
- 벤치마크 변형 약 20개(상한 3~8, 전투병 우위일 때만 깃발병 추가, 공학관·학생회관 가치 조합)

## 사람이 한 것

- 지금까지의 개선이 너무 작다는 판단과, 상대 리플레이에서 큰 경향을 찾자는 방향 제시(1번)
- 제안된 후보 중 1번(생산 극대화)부터 하기로 결정(2번)
