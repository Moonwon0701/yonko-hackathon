# 게임 규칙·API 인테이크

규칙이 공개되면 **가장 먼저 이 문서를 채웁니다.** 코드를 먼저 쓰지 않습니다.

이 문서는 답을 적어두는 곳이지 추측을 적는 곳이 아닙니다. 아직 모르는 항목은 빈칸으로 두고
`?`를 답에 적어 두세요. 빈칸이 남아 있다는 사실 자체가 정보입니다 — 운영진에게 물어볼 목록이
11절에 자동으로 쌓입니다.

## 어떻게 쓰는가

1. 규칙·API 문서가 공개되면 셋이 **같이 앉아 30분 안에** 1~9절을 채웁니다. 혼자 채우지
   않습니다. 세 명이 같은 그림을 갖는 것이 이 문서의 목적입니다.
2. 각 절 끝의 **→ 결정되는 것**은 그 답이 어느 파일의 설계를 정하는지 나타냅니다.
   채우고 나면 그대로 작업 분배가 됩니다.
3. 채운 뒤에야 `agent/world.py`부터 코드를 시작합니다. 순서는 아래와 같습니다.

   ```
   이 문서 작성 → world.py 확정 → adapter.py → 더미 strategy로 한 판 끝까지 → 그다음 BT
   ```

4. 대회 중 규칙이 바뀌면 **12절에 기록하고** 해당 절의 답을 고칩니다. 채팅에만 남기지 않습니다.
