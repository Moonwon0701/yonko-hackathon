## 목적

- 공학관을 덜 잃게 한 전선 유지의 효과를 승률로 이어지게 하고, 직선 돌파 공격이 통하는지 확인

## 범위 — LLM이 한 것

- `agent/strategy.py`(테마 브랜치): `LINE_EXTRA`·`LINE_PATHS`·`LINE_KINDS`와 `line_cells`(최단 경로들의 길목 여러 칸),
  `SPEAR_FROM`·`SPEAR_UNTIL`·`SPEAR_EXTRA`·`SPEAR_VALUE`·`SPEAR_WIDTH`와 `spear_tasks`, 트리 잎 `spear()`를 8개 국면 가지에 추가.
  결과가 나빠 모두 끈 채 남김
- 켠 상태의 예외 검사(저장한 20경기 입력으로 decide 직접 실행 — `main.py`가 예외를 삼켜 대전에서는 버그가 약한 봇으로만 보이므로)
- 설정 8가지 대전과 후보 3개 확인 대전, `docs/benchmarks.md` 두 줄

## 사람이 한 것
