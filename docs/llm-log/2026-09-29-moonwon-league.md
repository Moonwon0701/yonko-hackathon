## 목적

- 팀의 다른 브랜치 봇, `main`, 흉내 봇, 옛 버전과 문원 테마 브랜치 최신을 한 번에 비교해 가장 강한 봇을 찾는다.

## 범위 — LLM이 한 것

- `git fetch`로 모든 브랜치를 받고, 브랜치마다 `main.py`·`agent/` 트리 해시를 비교해 실제로 다른 봇만 골랐다. 성혁
  브랜치와 현진 `rush-delay`·`unit-rush`는 `fb1fe8f` 이전 `main` 코드(행동 동일)라 대표로 성혁 브랜치 하나만 넣었다.
  현진 `rally-reserve`의 실험 봇(`experiments/rally/main.py`)은 저장소 최상위를 기준으로 불러오므로 그 커밋을
  `runs/bots/rally-5fe7583/`에 꺼내 돌렸다(커밋 안 함).
- `scripts/league.py`: 봇 여러 개를 모든 쌍으로 붙이는 리그. 생성 맵(`--seeds`) 또는 서버 맵(`--maps`), 쌍별 승점률 표와
  평균 순위, 경기 기록 jsonl.
- 봇 9개로 생성 맵 50개·서버 맵 49개 리그를 돌려 `docs/benchmarks.md`에 "리그" 절을 새로 만들어 적었다.
