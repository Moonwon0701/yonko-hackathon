## 목적

- M1까지는 전투병이 적 깃발병만 쫓고, 깃발병은 적 전투병이 기다리는 칸에도 들어가며, 깃발 뽑기를
  노리지 않았다. 1번 질문의 답에서 정리한 약점(지키기 없음, 위험 무시, 기다리기 없음)을 고치기 위해

## 범위 — LLM이 한 것

- 1번: M1 코드에서 유닛이 멈추는 경우(목표 위, 목표 없음 등)와 M2로 이어지는 약점 설명
- `agent/algorithms.py`(성혁 담당): `threat_map` 추가
- `agent/strategy.py`(현진 담당):
  - 전투병 과제(적 깃발병 처치·깃발 뽑기·방어, 점령 중 깃발병 호위)와 필요 인원 기반 배정 `assign_warriors`
  - 깃발병 안전 이동 `flag_step`(적 위협 ≤ 우리 전투병인 칸만), 깃발 뽑기 때 전투병 도착까지 대기
  - 전투병 목표 수 = 적 전투병 + 1 (최소 3), 적의 이번 턴 본진 생산분도 위협에 포함
  - 자체 대전이 비대칭이던 원인 두 가지를 찾아 고침: (1) 동점 처리 순서가 절대 좌표·id 기준이라 진영마다
    달랐음 → 자기 본진 기준 정규화 좌표로, (2) 캠퍼스 역 판별이 "본진에서 가장 가까운 역"이라 중앙 서울역을
    잘못 고르고 동점을 id로 가름 → "본진 쪽으로 가장 치우친 역"으로
- `tests/test_strategy.py`: M2 테스트 5개(위협 맵, 위험 회피, 깃발 뽑기 동시 진입, 대기, 자체 대전 점대칭)
- `docs/benchmarks.md`, `docs/roadmap.md`(M1 완료, M2 구현 요약) 갱신
- 새 수치(KILL_VALUE 1.0, DANGER_DISCOUNT 0.5 등)는 LLM이 정한 첫 값이며 아직 튜닝하지 않음
