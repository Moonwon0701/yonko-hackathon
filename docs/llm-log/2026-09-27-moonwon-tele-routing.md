## 범위 — LLM이 한 것

- 1번: 순간이동도 한 턴을 쓰므로 역끼리 비용 1 간선으로 BFS에 넣으면 된다는 설계, 턴당 1회·5명·한 병종 제약 처리 방법 설명
- 2번 앞부분: 새 `main`(f564d8b)으로 ZIP 생성. 전체 테스트 중 `tests/test_official.py::test_devtool_is_unmodified` 실패를
  발견 — `.gitignore`의 `dist/` 때문에 PR #30에서 `devtool/bots/dist/`가 커밋되지 않은 것(제출 ZIP과 무관, 다른 세션 담당이라 고치지 않음)
- `agent/algorithms.py`(성혁 담당): `distance_map`·`step_along`에 `portals` 인자 (비면 기존과 같음)
- `agent/strategy.py`(현진 담당): 우리 역 2개 이상이면 전투병 이동 방향을 역 포함 거리표로 정하고, 턴당 인원이 가장 많은
  (출발 역, 도착 역) 하나만 `Tele`(최대 5명), 나머지는 걸어서만 거리표로 이동
- 변형 실험(깃발병만/전투병만/둘 다) 후 효과가 확인된 전투병만 남기고 나머지 코드를 뺌
- `tests/test_strategy.py`: 역 간선 거리, 5명 제한 순간이동 테스트
- `docs/benchmarks.md`, `docs/roadmap.md`(M4 표)
