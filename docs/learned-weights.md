# 학습한 상황별 가중치 풀이 (보고서용)

최종 후보 봇(`moonwon/loss-1001` `0a15a9e`)과 `main` 봇(`ee4ea4b`)에 들어 있는 학습 층 가중치 W를 상수마다 풀어 쓴 문서다.
두 봇의 `agent/learned.py`는 같다(ES 4차 180세대, `runs/es/20261001-034749/theta_g180.json`). 숫자는 이 문서를 만든 스크립트가
`agent/learned.py`·`agent/strategy.py`에서 직접 계산했다.

## 학습 층이 하는 일

판단 구조(행동 트리·과제·배정)는 규칙 그대로 두고, **"지금 상황에서 어느 과제를 얼마나 중시할지"만** 매 턴 바꾼다.

```
상수 = 기준값 × exp(clip(Σ W[상수][i] × 특징[i], ±2.5))      정수 상수는 반올림(하한 있음)
```

- 기준값은 `agent/strategy.py`에 적힌 값(사람이 실험으로 고른 값)이다. W가 0이면 기준 봇과 똑같이 움직인다.
- 배수 범위는 exp(±2.5) ≈ 0.08 ~ 12배.
- W는 진화 전략(OpenAI-ES, `scripts/es_train.py`)으로 상대 풀과의 대전 승점만 보고 찾았다. 소스 안의 상수라 규정상 허용된다(`docs/game-api.md` 12절). 학습 경과와 검증은 `docs/benchmarks.md` "학습 (진화 전략)".
- 상수 37개 × 특징 8개 = 296개 숫자.

### 특징 8개 (매 턴 계산, `learned.features`)

| 특징 | 계산 | 흔한 범위 |
| --- | --- | --- |
| bias | 1 (늘 같음 → 기본 배수) | 1 |
| 턴 | 턴 / 80 − 1 | −1(시작) ~ 0(80턴) ~ 1(160턴) |
| 전투병 차 | (우리 − 적 전투병) / (합 + 10) | −0.5 ~ 0.5 |
| 건물 수 차 | (우리 − 적 건물 수) / 8 | −0.6 ~ 0.6 |
| 공학관 차 | (우리 − 적 공학관 수) / 2 | −1 · −0.5 · 0 · 0.5 · 1 |
| 학생회관 차 | (우리 − 적 학생회관 수) / 2 | 같음 |
| 남은 자원 | 우리 자원 / 40 | 0 ~ 1 (턴 끝 평균 약 0.33) |
| 침입 | 우리 본진 쪽에 온 적 전투병 / (적 전투병 + 5) | 0 ~ 0.6 |

### 표 읽는 법

- **균형 배수**: 80턴, 전투병·건물·공학관·학생회관 차이 0, 자원 13, 침입 0일 때의 배수와 그때의 실제 값.
- **상황별 배수**: 균형 상황에서 특징 하나만 바꿨을 때의 배수(기준값 대비). 20턴 / 140턴, 전투병 크게 앞섬(차 +0.4 ≈ 70 대 30) / 뒤짐, 건물 3개 앞섬 / 뒤짐, 적 침입 많음(0.5).
- **읽는 법** 문장은 특징이 흔히 움직이는 폭 안에서 배수가 1.15배 넘게 바뀌는 것만 적었다.
- 주의: 가중치는 "이 상황에서 이렇게 하니 이겼다"는 상관이지 인과가 아니고, 상수끼리 서로 맞물려 하나만 떼어 해석하면 틀릴 수 있다. 학습 승점의 흔들림도 커서(세대마다 ±5%p) 작은 가중치(|W| < 0.15)는 잡음일 수 있다.

## 요약: 학습이 사람이 고른 값을 어떻게 바꿨나

균형 상황 배수 기준(아래 상수별 절과 끝의 "한눈에 보기" 표의 숫자).

- **크게 키운 것 = 경제 건물과 깃발병 싸움.** 초반 중립 건물 점령(`OPENING_NEUTRAL` ×2.98), 학생회관 가치(`HALL_VALUE_PER_TURN` ×2.97),
  적 깃발병 처치(`KILL_VALUE` ×2.68), 잃은 공학관 되찾기 점령(`RETAKE_CAPTURE` ×2.52), 수비 깃발(`FLAG_GUARD_WEIGHT` ×2.45),
  양동 점령(`DIVERSION_CAPTURE` ×1.84), 공학관 가치(`FUNCTION_VALUE.ENG` ×1.68), 호위(`ESCORT_VALUE` ×1.50). 사람이 실험으로 고른
  기준값보다 "경제 건물을 먼저 먹고, 적 깃발병을 잡고, 잃으면 바로 되찾는" 쪽을 훨씬 중시한다.
- **줄인 것 = 멀리 가는 것과 부풀린 인원.** 점령 효용의 거리 보정(`ETA_OFFSET` 2 → 0.88: 먼 건물보다 가까운 건물), 상대 경제 건물
  빼앗기(`RAID_STEAL` ×0.57), 보급소(`DEPOT_VALUE` ×0.59), 경제 건물 몰아내기 추가 배수(`ECON_WEIGHT` ×0.69), 고립 병원(×0.72),
  깃발병 상한(`MAX_FLAGS` 6 → 4명), 전투병 최소 인원(3 → 2명), 40~79턴 호위 인원(4 → 3명), 러시 추가 인원(2 → 1명).
- **상황에 따라 바꾸는 것.** 경기 후반으로 갈수록 처치·초소·러시·선제 수비·학생회관·공학관 가치를 낮추고, 별동대·기동대·비용 교환·
  경제 건물 몰아내기를 올린다(초반엔 넓게 먹고 잡고, 후반엔 지키고 덩어리로 움직임). 적이 우리 진영에 많이 들어오면 호위·몰아내기·
  되찾기 점령을 올리고 깃발병 상한·고립 병원·역 가치를 낮춘다(수비 전환). 학생회관을 우리가 더 가지면 양동·러시를 낮추고 탈환·
  기동대·수비 깃발을 올린다(앞서면 지키기).
- 선제 수비 거리(`EARLY_GUARD`)는 6 → 8걸음으로 넓어졌다(사람이 6·8걸음을 비교했을 때 둘이 비슷했던 것과 맞음,
  `docs/benchmarks.md` "수비 스위치").
