- 직접 대결 약 3만 판(새 시드 8000~9299, 서버 맵 85개). 결과는 `docs/benchmarks.md` 해당 절:

  - 예측: 깃발병 안전에 쓰면 3~8%p 나빠짐(공학관 러시 88.7 → 81.0%), 처치 칸 예측은 흔들림 안.
  - 스타일: 서버에서 진 강팀은 "전투병 넓게 · 호위 없는 깃발병 접근 드묾"으로 구별되지만, 대응 설정 11가지 중 기준보다 확실히 나은 것이 없음.
