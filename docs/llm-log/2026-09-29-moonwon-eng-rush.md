- 날짜: 2026-09-29
- 요청한 사람: 문원
- 모델: Claude Opus 5.5 (`claude-opus-5-5`), Claude Code CLI
- PR: 없음 (테마 브랜치 `moonwon/eval-tuning`)

## 프롬프트 (원문 그대로)

1. (리그에서 흉내 봇 "공학관 러시"가 테마 브랜치를 이긴다고 보고하고 "테마 브랜치에 공학관 러시를 합쳐 볼까요?"라고 묻자)
   > 공학관 러시 합쳐보자 고고

## 목적

- 리그 1~2위였던 흉내 봇 `opponents/eng_rush.py`의 요소(공학관 러시, 상대 건물 초소)를 테마 브랜치 전략에 넣어 더 강한
  봇을 만든다. 호위는 이미 켜져 있다.

## 범위 — LLM이 한 것

- `agent/strategy.py`: 스위치 상수 `RUSH_UNTIL`·`RUSH_EXTRA`·`RUSH_VALUE`·`RUSH_CAPTURE`(공학관 러시)와 `PICKET_VALUE`(초소),
  과제 만들기 `rush_tasks`·`picket_tasks`, 국면 트리 네 가지 모두에 두 과제 잎, 점령 가치에 러시 중 공학관 배수. 기본값을
  끈 채로 넣고 결과가 전과 같은지 확인했다.
- `scripts/tune.py` 격자에 다섯 스위치를 넣고 두 바퀴 탐색 → `RUSH_UNTIL=60`, `PICKET_VALUE=1.0` 채택. 새 시드, 리그(생성 맵·
  서버 맵), 옛 버전·스타터 상대로 확인한 뒤 기본값으로 켰다.
- `tests/test_strategy.py`: 러시가 상대 쪽 공학관에만·러시 턴까지만 나오는지, 초소가 상대 건물 중 적 깃발병 없는 곳에만
  나오는지 테스트 두 개.
- `docs/benchmarks.md` "파라미터 탐색"에 한 줄, "리그"에 두 줄.

## 사람이 한 것

- 문원: 공학관 러시를 테마 브랜치에 합치기로 정했다.

## 검증

- 새 시드 3000~3049 상대 풀 60.4 → 67.6%.
- 리그: 생성 맵 1위 63.3%, 서버 맵 1위 66.3%(모든 상대에게 이김). 생성 맵에서 흉내 봇 "공학관 러시" 상대는 46%.
- M4 96%, M3 100%, 스타터 lv2 100%, 최대 응답 15 ms.
- `pytest` 818개 통과, `ruff check .` 통과.
