## 목적

## 범위 — LLM이 한 것

- `scripts/analyze_games.py` (새 파일): 두 봇을 시드 × 진영으로 두고, 이긴 경기와 진 경기의 턴별 점수 차·건물 수
  차·전투병 차·깃발병 차, 건물 종류별 보유, 상대가 중립화한 우리 건물, 국면 비율을 비교해 출력
- 분석 (M4 `f564d8b` 상대 200경기, M3 상대 200경기): 진 경기는 전투병 차이가 먼저 벌어지고 점수가 뒤따른다.
  전투병은 전투에서 1:1로 상쇄되므로 차이 = 생산량 차이 → 생산을 바꾸는 공학관·학생회관 보유가 30~60턴부터 기운다
- `agent/strategy.py`: 공학관 기능 가치 0.5 → 2.0 (한 줄 + 근거 주석)
- 실험: 공학관 1.0·2.0·3.0, 학생회관 턴당 0.04 단독·조합을 `main`·M4 상대로, 채택안은 다른 시드·M3·lv2로 재확인
- `docs/benchmarks.md`, `docs/roadmap.md`에 결과 기록
