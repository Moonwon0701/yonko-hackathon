  **0승 0무 50패** (95% 구간 0–7%), 평균 점령 점수 3.2 vs 31.8, 몰수 0, 최대 응답 23 ms
- 결론: 이대로는 채택하지 않는다

## 2차: 공격 경로가 반드시 집결지를 거치게

### 프롬프트 (원문 그대로)

3. > 그러면 공격하는 루트를, 무조건 집결지를 거쳐서 하게 해줘봐

### 범위 — LLM이 한 것

- `agent/strategy_rally.py`를 다시 썼다: 과제 없는 전투병의 공통 목표는 main과 같게 되돌리고, 집결지를 아직
  안 거친 인원만 먼저 집결지로 보낸다. "거친 인원"은 칸별 인원(`_passed`)으로 턴을 넘어 기억한다(이동 뒤 칸으로
  옮겨 적고, 다음 턴 실제 인원으로 자른다 — 전투 손실·합류는 근사). 트리는 "전투병" 가지의 잎 두 개
  (과제 배정·이동)만 바꿔 끼운다. 과제를 받은 전투병은 main처럼 곧장 간다

### 검증

- 대조: 집결지를 끈 봇 vs `git:main` `sim diff` → 10경기 1600턴 명령이 모두 같음
- `python -m sim arena experiments/rally git:main --seed 100 --seeds 25` (50경기):
  **10승 0무 40패** (승점률 20%, 95% 구간 11–33%), 평균 점령 점수 10.8 vs 23.5, 몰수 0, 최대 응답 22 ms
- 결론: 1차(0승)보다 낫지만 main보다 확실히 약하다. 채택하지 않는다
