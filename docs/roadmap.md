## 전략 구조: 지금과 목표

**지금 (M1까지): 효용 AI + 고정 순서.** `decide`는 매 턴 같은 순서로 한 번씩 실행된다. "지금 무엇을 할까"를
고르는 단계가 없어 늘 "확장"만 한다. 판단은 건물 효용 점수가 맡고, 전투병은 lv2에서 가져온 고정 규칙이다.

```
1. 목표 건물 고르기 → 효용 점수 매기기
2. 깃발병 배정 (효용 큰 짝부터)        ← 효용 기반
3. 점령 비용 예약 → 생산
4. 깃발병 이동 + PRIORITY
5. 전투병 이동 (적 깃발병 추격)         ← 고정 규칙
```

**목표 (M3): BT 위층 + 효용 아래층.** 위층이 국면을 고르고, 각 국면은 아래층 효용 배정기를 가중치만
바꿔 다시 쓴다(예: 굳히기 = 우리 건물 방어 가치 ↑, 공격 = 상대 건물 가치 ↑).

```
Selector (위에서부터 처음 성립하는 가지 실행)
├─ [본진·건물이 위협받나?] → 위협 대응
├─ [점수 앞서고 후반인가?] → 굳히기
├─ [약한 적 건물이 있나?]  → 공격
└─ 확장  ← 지금 decide가 하는 일은 사실상 이 가지 하나
```

아래층(M1·M2)을 먼저 만드는 이유: BT는 "언제 무엇을 할지"를 정하는 틀일 뿐, 실제로 유닛을 움직이는
부품은 아래층이다. 부품이 있어야 BT 가지가 호출할 것이 생긴다.

## M0. 기준선 확보 — 완료

- `main.py`가 stderr에 INIT 원문(서버 맵 재현용)과 턴당 한 줄 로그를 남긴다
- 로컬 기준선: lv1 100승, lv2 100무(같은 봇). 서버 모의 전투는 미측정

## M1. 목표 분산 + 건물 가치

- 건물 가치 = 추정 점수(모르면 진영 1.5 / 중앙 3.0, 대칭 짝·광장으로 추론) + 기능 가치(학생회관·보급소 등)
- 효용 = 가치 / (거리 + 점령 단계 + 2). 깃발병 한 명씩 탐욕 배정, **한 건물에 한 명**
- 점령 비용은 이번 턴 수입으로 못 메우는 만큼만 예약, 남는 자원은 전투병
- 동시 점령 2곳 이상이면 `PRIORITY`
- 결과(로컬): lv2 상대 100승. 목표 분산만으로 86승, 남는 자원 → 전투병이 나머지를 뒤집음

## M2. 위험 판단 + 깃발 뽑기

구현 요약 (`agent/strategy.py`):
- `threat_map`: 적 전투병 무리가 제자리·한 칸으로 모일 수 있는 최대 인원 + 이번 턴 적 본진 생산 가능분
- 전투병 과제(`warrior_tasks`): 적 깃발병 처치(건물 위면 그 건물 가치 추가 — 방어·점령 저지·깃발 뽑기),
  점령 중인 우리 깃발병 호위. 과제마다 필요 인원(적 위협 + 1, 호위는 같은 수)을 채울 수 있는 것 중
  가치 / (1 + 가장 먼 전투병 거리)가 큰 것부터 배정. 남는 전투병은 lv2처럼 적 깃발병 추격
- 깃발병(`flag_step`): 이동 뒤 칸의 적 위협 ≤ 우리 전투병이어야 들어간다. 아니면 대기 → 피하기
- 깃발 뽑기: 전투병 과제가 잡힌 적 깃발병 건물만 깃발병 목표가 되고, 전투병이 이번 턴 도착하지 못하면
  깃발병은 한 칸 앞에서 기다린다
- 전투병 수: 적 전투병 + 1 (최소 3)
- 동점 처리를 자기 본진 기준 정규화 좌표로 맞춰 자체 대전이 점대칭이 되게 함. 캠퍼스 역 판별도
  "본진에서 가장 가까운 역" → "본진 쪽으로 가장 치우친 역"으로 고침(중앙 서울역을 잘못 고르던 맵이 있었음)

- **algorithms:** 영향력 맵 `threat_map` — 다음 턴 적 전투병이 닿을 수 있는 칸과 그 인원 수
- 깃발병은 적 전투병이 더 많이 닿을 수 있는 칸으로 들어가지 않는다 (경로 비용에 위험 반영)
- 전투병 역할 분담: **요격**(우리 건물을 노리는 적 깃발병) · **호위**(점령 중인 우리 깃발병) · **공격**(깃발 뽑기)
- 전투병 상한 3을 없애고 적 전투병 수에 비례해 목표 인원을 정한다

### 핵심 전술: 깃발 뽑기 (문원 아이디어, 원문 6장·7장)

상대 소유 건물 위의 수비 깃발병을 전투로 제거하면 그 건물은 **전투 단계에서 즉시 중립**이 되고, 같은 칸에
내 깃발병이 살아 있으면 점령 단계에서 바로 내 소유가 된다 (`rules-original.md` 289·312줄).

| | 일반 점령 (중립화 → 점령) | 깃발 뽑기 (전투병 + 깃발병) |
| --- | --- | --- |
| 내 자원 | 2+2 = 4 (광장 8) | 2 (광장 4) |
| 걸리는 턴 | 최소 2턴 | 1턴 |
| 상대 손실 | 건물만 | 건물 + 깃발병(5) + 그 건물에 쓴 점령 비용 |
| 누적 점령-턴 | 상대가 1턴 더 쌓음 | 즉시 끊김 |

- 조건: 그 칸에서 내 전투병 수 > 상대 전투병 수
  - 수비 깃발병이 있으면 깃발병만 들어가도 **경합**이라 점령이 안 된다. 이 경우 전투병은 필수다
  - 빈 건물은 뽑을 깃발이 없으므로 일반 2단계로만 뺏을 수 있다
- 전투병만 보내도 깃발은 뽑힌다(중립화, 내 비용 0). 깃발병은 다음 턴에 2로 점령
- 동시 턴이라 상대 깃발병이 그 턴에 떠날 수 있다. 전투병과 깃발병이 **같은 턴에 도착**하도록 깃발병은 한 칸 앞에서 대기
- 효용 반영: 수비 깃발병이 있고 적 전투병이 약한 상대 건물은 비용·턴 절감 + 처치 보너스만큼 가치를 올린다
- **방어(역방향):** 점령을 마친 우리 깃발병이 건물 위에 머물면 뽑힐 표적이 된다. 소유는 떠나도 유지되므로
  적 전투병이 닿을 수 있으면 비킨다. 2턴 걸리는 상대 건물 공략 중에는 전투병 호위를 붙인다
- 효과는 상대 봇이 건물 위에 깃발병을 남기는 빈도에 달려 있다 → 모의 전투 기록에서 확인

## M3. BT 국면 선택

- `choose_phase(world, memory) -> Phase` → 국면별 효용 가중치 → M1·M2 배정기
- 국면 4개(우선순위 순): 위협 대응 → 굳히기 → 공격 → 확장 (위 구조도)
- 직전 국면을 기억하고 임계값에 여유 폭(히스테리시스)을 둬 국면이 턴마다 바뀌지 않게 한다
  - `decide` 호출 사이의 상태가 필요하다. 모듈 수준 메모리 또는 `World` 필드 추가 중 선택
- stderr에 턴마다 선택한 국면을 남긴다 → 보고서 "유닛 운용" 자료
