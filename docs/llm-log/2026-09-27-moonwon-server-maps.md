  실제 서버 맵과 실제 점수로 로컬 검증을 하기 위해

## 범위 — LLM이 한 것

- 리플레이 21개 분석: 내용이 같은 중복 2개(상급 `...-pov.json` = `replay (8).json`, 중급 `replay (6).json` =
  `replay (5).json`)를 찾아 빼고 19개를 `data/server-replays/`로 옮김. 고유 맵은 10개(중·상 봇이 같은 맵 사용),
  10개 모두 17개 건물 점수가 공개돼 있음을 확인
- `sim/mapgen.py`: `from_server_replay`, `load_server_maps`(같은 지형 묶기, 공개 점수 합치기, 본진 진영 판별)
- `sim/arena.py`, `sim/__main__.py`: `arena --maps <폴더>`, `--map-file`에 `.json` 지원
- `tests/test_sim_server_maps.py`: 맵 10개, 규칙 조건(점대칭·17건물·짝 점수·광장·총점 홀수·도달 가능), 한 판 진행
- `docs/simulator.md` 사용법, `docs/benchmarks.md` 서버 맵 결과
