# 문원 테마 봇에 현진 테마 별동대를 합쳐 main으로 옮기기

- 날짜: 2026-09-29
- 요청한 사람: 문원
- 모델: Claude Opus 5.5 (`claude-opus-5-5`), Claude Code CLI
- PR: #53 (브랜치 `moonwon/merge-squad`)

## 프롬프트 (원문 그대로)

1. > 현진 브랜치 봇 (별동대) vs 내 브랜치 봇/ 현진 브랜치 봇 vs 공학관 러쉬 GUI 띄워줘
2. > 여러개 돌려서 현진 봇의 장점/ 내 단점이 보이는 결과 띄워줘
3. > 어떤걸 개선하면 좋을까
4. > 현진이 봇하고 내 브랜치 봇 하고 병합하는 건 협업 규칙에 따라 내 병합 브랜치에서  진행해야할 작업이야. 진행해주고 main에서 풀 받자.

(1~3은 파일을 고치지 않은 분석이다. 1은 `python -m sim match`로 두 경기 리플레이를 띄웠다. 2는 `python -m sim arena`와
`scripts/analyze_games.py`로 현진 테마 상대 100경기를 두고, 진 경기 세 판(시드 4·2·8)을 띄웠다. 3은 두 브랜치 전략 코드의
차이(별동대·초소·러시 기간)를 하나씩 바꾼 변형을 저장소 밖 임시 폴더에 만들어 대전했고, "별동대를 옮기자"고 제안했다.
LLM은 처음에 문원 테마 브랜치에서 옮기자고 했는데, 4에서 문원이 통합 브랜치에서 하도록 바로잡았다)

## 목적

- 현진 테마 봇이 문원 테마 봇을 72%로 이기는 이유를 찾고, 그 원인이 된 부분을 `main`에 합친다

## 범위 — LLM이 한 것

- 분석(파일 변경 없음): 진 경기에서 30~59턴 공학관·보급소를 잃어 전투병 생산이 벌어진다는 것을 턴별 집계로 확인. 양쪽 모두
  자원 상한에 걸린 턴이 없음(= 전투병 차는 낭비가 아니라 수입 차). 하나씩 바꾼 변형 대전으로 별동대가 차이의 거의 전부임을 확인
- `agent/strategy.py`, `tests/test_strategy.py`: 문원 테마 브랜치(`moonwon/eval-tuning` `2b71430`, 봇 코드는 `efceb56`과 같음)의
  파일을 그대로 가져온 뒤, 현진 테마 브랜치(`hyunjin/defense-econ` `1672fe2`)의 별동대(`SQUAD_SIZE`·`SQUAD_WEIGHT`·
  `SECOND_SQUAD_TURN`, `squad_tasks`, 트리 잎 `squad()`)를 옮겨 네 국면 가지의 러시 앞에 넣었다. 모듈 설명 한 줄 추가
- `tests/test_strategy.py`: 별동대 단위 테스트 1개 추가(위험한 목표로 가는 깃발병의 다음 칸에만 SQUAD_SIZE명)
- `docs/benchmarks.md`: 문원 테마 브랜치의 판을 가져오고, "로컬 아레나 — 서버 맵" 표 끝에 원인 측정과 통합 결과 두 줄 추가
- `docs/llm-log/`: 옮기는 코드의 기록 `2026-09-29-moonwon-rush-safe.md`(문원 테마), `2026-09-28-hyunjin-squad.md`·
  `2026-09-29-hyunjin-theme-branch.md`(현진 테마, 별동대)를 가져오고 이 파일을 만들었다
