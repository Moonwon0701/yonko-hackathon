## 목적

- 로드맵 M4(건물 기능 활용)를 진행하되, 첫 턴 실험처럼 효과가 확인되지 않는 변경은 넣지 않기 위해 기능마다 따로 재서 반영

## 범위 — LLM이 한 것

- `agent/strategy.py`(현진 담당): `spawn_site` — 본진·우리 병원 중 목표(깃발병: 미점령 건물, 전투병: 과제·공통 목표)에
  가장 가까운 곳에서 생산, 적 전투병이 닿는 병원은 제외, 동점이면 본진
- 역 순간이동(`choose_tele`)을 구현해 재 봤으나 합계 약 50.8%로 효과가 없어 코드를 뺌
- 정찰병은 구현 전에 "모든 점수를 처음부터 아는 봇" 상한 실험(시뮬레이터를 스크립트 안에서만 조작)을 해 49%가 나와
  만들지 않음. 이 결과가 맵별 점수 선지식(운영팀 질문 3번)도 지금 전략에서는 이득이 없다는 근거가 됨
- `tests/test_strategy.py`: 병원 생산 테스트 2개, 대칭 테스트의 좌표 뒤집기에 병원 SPAWN·TELE 추가
- `docs/roadmap.md`, `docs/benchmarks.md` 갱신
- 실수: 작업 중 설명 없이 `git stash`/`git stash apply`를 실행해 stash 항목이 남았고, 작업 파일과 같은 것을 확인한 뒤 지움
