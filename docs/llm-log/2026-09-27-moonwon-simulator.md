## 프롬프트 (원문 그대로)

1. > 이제 자체적인 모의 전투를 돌려볼 수 있는 시뮬레이터를 제작해보자. 용도는 다음과 같아. 1. 빠른 검증: 로컬 시뮬레이션을 통해서 개선한 에이전트가 더 좋은 성과를 보이는지 빠르게 검증해. 2. 육안으로 확인: 개선 부분이 실제 시뮬레이션 GUI에서 돌아가는 것을 확인해 개선부분이 정성적으로 좋은 결과를 보이는지 확인해. 또한 추가적인 개선점을 발견할수도 있지. 우선 제작하고 실제 게임환경과 같은지 검증이 가능하다면 검증해줘.

## 범위 — LLM이 한 것

- `sim/rules.py`: 규칙 수치 (규칙서 부록·스타터 `BALANCE`에서 옮김)
- `sim/mapgen.py`: 규칙서 1장 조건을 지키는 맵 생성기, 서버 INIT 블록으로 맵 불러오기
- `sim/engine.py`: 규칙서 4~10장 턴 처리 엔진. 명령 줄마다 처리/일부 처리/무시와 이유를 기록.
  규칙서로 정해지지 않는 부분은 `ASSUMPTIONS`에 명시
- `sim/bots.py`, `sim/match.py`: 봇을 서버처럼 별도 프로세스로 실행(시간 제한 3초/300 ms, END·flush·
  출력 한도·조기 종료 확인), 리플레이 기록. `git:<ref>`로 과거 커밋 봇 실행
- `sim/arena.py`, `sim/__main__.py`: 시드 × 진영 교대 병렬 대전, 승점률과 95% 구간 요약, CLI
- `sim/viewer.html`, `sim/viewer.py`: 오프라인 리플레이 뷰어(보드·이동 화살표·전투/점령 표시·명령
  목록·이벤트·stderr·점수 그래프)
- `tests/test_sim_rules.py`, `tests/test_sim_match.py`: 규칙서 장별 시나리오, 스타터 킷 파서 호환,
  자기 대전 점대칭, 몰수 처리 테스트
- `docs/simulator.md` 작성, `docs/game-api.md` 11절 갱신(시뮬레이터 담당 결정, 채널톡 질문 후보 추가)
- 작업 전 머지된 브랜치 `moonwon/rules-and-llm-log` 정리

- 엔진 상수와 스타터 `BALANCE` 항목별 일치, 시드 300개 맵이 규칙서 1장 조건 만족
- 규칙서 예시(전투 표 4줄, 무효 명령 예시 5개)를 그대로 재현

  공정하게 처리
- 우리 봇(스타터 lv2 이식본) vs 스타터 lv2: 16:16 무승부(누적 점령-턴까지 같음), vs lv1: 40전 40승,
