## 목적

- 학습 층 가중치(W, 상수 37개 × 특징 8개)가 각 상수를 언제 얼마나 키우고 줄이는지 보고서("유닛 운용"·"개발 과정")에 쓸 수 있게
  풀어 쓴다

## 범위 — LLM이 한 것

- `docs/learned-weights.md` 새로 작성
  - 숫자(가중치, 균형 상황 배수와 실제 값, 상황별 배수, "읽는 법" 문장)는 일회용 스크립트(저장소에 넣지 않음)가 `agent/learned.py`의
    W와 `agent/strategy.py`의 기준값에서 직접 계산
  - 상수 설명과 "지금 봇에서 쓰이는가"(암살·고정 별동대 인원은 꺼져 효과 없음, 러시 60턴·초반 중립 30턴까지, `TRADE_BOOST`·`FLAG_INERTIA`는
    기준값 1이 끔이지만 학습 배수로 켜짐)는 코드 주석과 스위치 값을 보고 LLM이 씀
  - 앞부분 요약(크게 키운 것 · 줄인 것 · 상황에 따라 바꾸는 것)은 LLM이 표를 보고 씀 — 각 문장을 상수별 표의 부호·배수와 대조함
- `main`의 `agent/learned.py`가 최종 후보(`moonwon/loss-1001` `0a15a9e`)와 같음을 `diff`로 확인

## 사람이 한 것

- 양동 설명 방식을 보고 다른 가중치도 같은 방식으로 문서로 남기자고 정함

## 검증

- 스크립트가 `KNOBS` 37개와 설명 목록이 정확히 같은지 확인(빠지거나 남는 상수 없음)
- 양동 두 상수의 숫자가 채팅에서 손으로 계산한 값(균형 배수 ×1.31 → 3.92, ×1.84 → 2.76)과 같음
